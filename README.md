# Pouyan Trade Pro v7
نسخه کامل‌تر رابط وب پروژه.

شامل: داشبورد، نوار خرید/خنثی/فروش، نمودار، RSI/EMA/MACD، حجم، OI/Funding، اسکن 100 نماد، جهش فشار، جلسات جهانی، اقتصاد کلان، اخبار، نهنگ‌ها، اعلان، صدا، فارسی/English، تم، تنظیمات مدیر و بخش بک‌تست.

محدودیت مهم: داده واقعی Top Traders/Whales/News/Macro و احراز هویت امن نیازمند API و backend هستند. این نسخه از جعل داده جلوگیری می‌کند. برای احتمال موفقیت نیز باید بک‌تست واقعی اجرا شود.
